# Awesome Jev

A living directory of TypeSafe Jev demos, repositories, skills, reusable code, integrations, and independent reproductions.

The initial **17 primary-source-reviewed selections** are in [data/curated.json](data/curated.json). They cover the official SDKs and skill, Jevify, Jev Logs, Skillbox, Jev Ultrafast, Foreman, MCP servers, Home Assistant, Snake, Mario, JevPilot, Doom/Freedoom, music planning, and OpenJev SGLang.

[Reusable code examples](examples/README.md) · [Curator skill](skills/jev-curator/SKILL.md) · [Sources and licensing](SOURCES.md) · [Contributing](CONTRIBUTING.md)

The [refresh workflow](https://github.com/Amal-David/awesome-jev/actions/workflows/curate.yml) regenerates this README and the full catalog. It imports attributed CC0 community metadata, searches GitHub independently, checks candidate READMEs, refreshes repository metadata, and publishes directory updates every four hours at `23 */4 * * *` UTC. Automatic discoveries remain visibly distinct from editorial review.

This directory is unofficial. Source review is not an execution test, security audit, or benchmark replication. Linked projects retain their own licenses. The examples and 30-test suite run offline by default; no model credentials or spending are needed for curation.
