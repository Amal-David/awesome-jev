# Web sweep: September 25, 2026

[Reviewed picks](REVIEWED.md) · [Selection policy](CURATION.md)

This was a bounded discovery and source-review pass, not an exhaustive inventory of the internet. Leads came from [All about Jev](https://hanxiao.io/all-about-jev/), [Ship with Jev](https://www.shipwithjev.com/), [jev.page](https://jev.page/updates), GitHub repository/code search, and English and Chinese web searches including paper and model indexes. Directory listings were leads, not evidence of implementation quality.

Five projects were selected for distinct, inspectable uses. Their pinned README and code links are in `data/curated.json`; the additional sources below explain the review. No discovered project, skill, test suite, model, game, or installer was executed. No provider key, private dataset, database connection, registry login, or paid inference was used. Repository build tests are separate from upstream-project validation.

## Selected

### AnyJev — independent model research

Readout correction and calibration for open models, not TypeSafe weights or an official implementation. The source distinguishes raw/L0 option readouts, L1 temperature calibration, and L2 heads fitted for a particular question and model. L0 is not calibrated and its rotations require additional prefills. The letter readout has a 26-option limit. Author measurements include teacher-labeled tasks and are not reproduced by this list.

Reviewed at `795a4970b47218b7c0686cd579d691fc2cf8df2f`: [decider](https://github.com/nokia-applied-research/AnyJev/blob/795a4970b47218b7c0686cd579d691fc2cf8df2f/anyjev/decider.py), [synthetic head tests](https://github.com/nokia-applied-research/AnyJev/blob/795a4970b47218b7c0686cd579d691fc2cf8df2f/tests/test_heads.py), and [vLLM backend](https://github.com/nokia-applied-research/AnyJev/blob/795a4970b47218b7c0686cd579d691fc2cf8df2f/anyjev/backends/vllm.py). The latter sends prompt state and any supplied bearer key to its configured server without enforcing HTTPS. Local execution and a remotely served model are different data boundaries. The [code license is Apache-2.0](https://github.com/nokia-applied-research/AnyJev/blob/795a4970b47218b7c0686cd579d691fc2cf8df2f/LICENSE); model and dataset terms are separate.

### jev-align — definition optimization

Uses human labels and rationales to evaluate typed Jev definitions and propose changes through GEPA. This edits classifier instructions and rubrics, not model weights. It is an experimental workflow: a better training score alone does not establish improved generalization.

Reviewed at `3d997fc76593036655c28d4964de43b55f81fe2c`: [typed evaluator](https://github.com/sutro-sh/jev-align/blob/3d997fc76593036655c28d4964de43b55f81fe2c/src/jev_align/jev.py), [optimizer](https://github.com/sutro-sh/jev-align/blob/3d997fc76593036655c28d4964de43b55f81fe2c/src/jev_align/optimizer.py), and [mock evaluator test](https://github.com/sutro-sh/jev-align/blob/3d997fc76593036655c28d4964de43b55f81fe2c/tests/test_jev.py). Evaluator inputs reach the selected Jev provider. Reflection feedback includes row state, labels and rationales and reaches a separately configured model. Optional local input capture and public registry publishing need their own data review; published packages include labeled examples, not just definitions. [Apache-2.0](https://github.com/sutro-sh/jev-align/blob/3d997fc76593036655c28d4964de43b55f81fe2c/LICENSE).

### neo4jev — graph navigation

Jev chooses graph edges and checks goals; ordinary code owns candidate construction, beam width, depth and call budgets. Exact target-node stopping is separate from a model's semantic goal judgment. Candidate caps and shortened properties can omit useful evidence, so this is not complete graph-query execution. The supplied hash-vector lookup is a placeholder rather than a semantic embedding service.

Reviewed at `d157bbe496eb91813475156942bef1c6badfb342`: [navigator](https://github.com/jexp/neo4jev/blob/d157bbe496eb91813475156942bef1c6badfb342/src/neo4jev/navigator.py), [access-layer definitions](https://github.com/jexp/neo4jev/blob/d157bbe496eb91813475156942bef1c6badfb342/src/neo4jev/neo4j_access.py), and [fake-client traversal tests](https://github.com/jexp/neo4jev/blob/d157bbe496eb91813475156942bef1c6badfb342/tests/unit/test_navigator_scoring.py). Node and relationship properties, path context, and optional schema/property samples reach TypeSafe. Use a read-only database account with data approved for hosted processing. No demonstration database was accessed. [MIT](https://github.com/jexp/neo4jev/blob/d157bbe496eb91813475156942bef1c6badfb342/LICENSE).

### patdown — semantic linting

Markdown rules become typed checks, with optional follow-up classification to locate evidence among known source regions. The default judge is Jev through Effect; the judge service is replaceable. This is advisory linting, not an authorization system or proof that code is secure.

Reviewed at `c7c1c71cad29b8f630c314dcbd7fb5973610c11b`: [TypeSafe adapter](https://github.com/tyler-dot-earth/patdown/blob/c7c1c71cad29b8f630c314dcbd7fb5973610c11b/apps/patdown/src/typesafe-judge.ts), [finite probability validation](https://github.com/tyler-dot-earth/patdown/blob/c7c1c71cad29b8f630c314dcbd7fb5973610c11b/apps/patdown/src/patdown-judge.ts), and [mocked error/redaction tests](https://github.com/tyler-dot-earth/patdown/blob/c7c1c71cad29b8f630c314dcbd7fb5973610c11b/apps/patdown/tests/typesafe-judge-errors.test.ts). Source input reaches the judge; filename exclusions are not content sanitization. Custom `TYPESAFE_BASE_URL` does not require HTTPS. Error formatting excludes provider prose, but users must still protect the submitted source and use trusted HTTPS for real credentials. Evidence-location queries add calls. [0BSD](https://github.com/tyler-dot-earth/patdown/blob/c7c1c71cad29b8f630c314dcbd7fb5973610c11b/LICENSE).

### Jev-Mem — agent-memory research

Uses hosted Jev to control graph-memory organization and retrieval, with a separate language model for answers. It retains explicit request budgets, typed response checks, fallback events and a synthetic mock path. This is a direct Jev integration, not independent Jev weights.

Reviewed at `81574eb23f3fd8d1a6c4d54a1e7d6f2dd539e9bb`: [client](https://github.com/libingzheren/Jev-Mem/blob/81574eb23f3fd8d1a6c4d54a1e7d6f2dd539e9bb/memory/jev_client.py), [configuration](https://github.com/libingzheren/Jev-Mem/blob/81574eb23f3fd8d1a6c4d54a1e7d6f2dd539e9bb/memory/jev_mem_config.py), [offline-test source](https://github.com/libingzheren/Jev-Mem/blob/81574eb23f3fd8d1a6c4d54a1e7d6f2dd539e9bb/tests/test_jev_mem.py), and [security notes](https://github.com/libingzheren/Jev-Mem/blob/81574eb23f3fd8d1a6c4d54a1e7d6f2dd539e9bb/SECURITY.md). Observations/context reach Jev; answer generation, judging and optional hosted embeddings have additional provider boundaries. Custom TypeSafe URLs need trusted HTTPS. Caches retain conversation data and some persistence uses pickle: load only trusted files. The [paper](https://arxiv.org/abs/2609.23986) and README measurements are author-reported; the disclosed reference-aware best-of selection can bias evaluation, and example commands are not a reproduction protocol. [MIT](https://github.com/libingzheren/Jev-Mem/blob/81574eb23f3fd8d1a6c4d54a1e7d6f2dd539e9bb/LICENSE).

## Deferred after inspection

**Jev Foundation Models (Swift).** The bridge has a concrete typed-decision role, but at `22931967b9f04afe532eb67fb068253c4b0be8aa`, [ResponseSynthesizer.swift](https://github.com/peterfriese/jev-foundation-models/blob/22931967b9f04afe532eb67fb068253c4b0be8aa/Sources/JevFoundationModels/Response/ResponseSynthesizer.swift) substitutes defaults for missing answers, including the first choice, false, or a minimum score. [JevExecutor.swift](https://github.com/peterfriese/jev-foundation-models/blob/22931967b9f04afe532eb67fb068253c4b0be8aa/Sources/JevFoundationModels/JevExecutor.swift) passes the response to synthesis without first rejecting that incomplete answer set. Reconsider after missing/malformed answers produce an error or explicit abstention, with regression tests; a type-correct synthesized value must not imply a model decision occurred.

**JEV-Star.** The [macro client](https://github.com/sc2musa/Jev_Star/blob/07c6965003f0ac0079af10017b37f17694423fd2/macro/sc2_rl_agent/starcraftenv_test/agent/jev_agent.py) and [mock scheduler tests](https://github.com/sc2musa/Jev_Star/blob/07c6965003f0ac0079af10017b37f17694423fd2/macro/tests/test_jev_agent.py) show useful legal-action checks, bounded requests and stale-result handling. Held pending clearer reuse permissions: its [third-party notice](https://github.com/sc2musa/Jev_Star/blob/07c6965003f0ac0079af10017b37f17694423fd2/THIRD_PARTY_NOTICES.md) explicitly identifies imported macro code without a repository-wide license and assigns no blanket license. This is not a finding of infringement. Game, map and upstream code permissions need separate treatment; no game or planner was run.
